# Study Planner

A smart study planning and time-management application designed to help students organize academic tasks, manage deadlines, and build consistent study habits.

## Technology Stack

* **Frontend:** React, TypeScript, Tailwind CSS
* **Framework:** TanStack Start
* **Runtime & Package Manager:** Bun
* **Development IDE:** Antigravity
* **Development & AI Tools:** Lovable, Claude, Gemini

## Features

* Personalized study scheduling
* Task and deadline management
* Backlog and workload tracking
* Exam preparation planning
* Assignment management
* Dynamic time allocation
* Progress tracking
* Gamification and motivation features
* Habit-building and time-management support

## Development

### Prerequisites

Make sure you have **Bun** installed.

### Installation

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
```

### Run Locally

```sh
bun run dev
```

The application will start in development mode and can be accessed through the local development server.
